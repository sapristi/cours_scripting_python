# 3. Stack minimale utile (25 min)

## 3.1 IP + port

- **IP :** adresse de la machine (ex. `127.0.0.1` = localhost).
- **Port :** porte d'entrée vers un service (ex. `22` SSH, `80` HTTP, `443` HTTPS).
- Couple `(IP, port)` = adresse complète d'un service, comme en module 2 avec les `tuple` `(ip, port)`.

## 3.2 TCP vs UDP

| Protocole | Mode | Garantie | Usage cyber typique |
| --------- | ---- | -------- | ------------------- |
| `TCP` | connecté, fiable | ordre + retransmission | SSH, HTTP, scan `connect` |
| `UDP` | sans connexion | rapide, sans garantie | DNS, beaconing, exfiltration |

## 3.3 DNS et client-serveur

- **DNS :** annuaire `nom -> IP`. Une erreur DNS en Python = `socket.gaierror`.
- **Client-serveur :** le client `connect`, le serveur `bind + listen + accept`. Ici on ne code que le client.
- **Bannière :** texte renvoyé par un service à la connexion. Bannière verbeuse = fuite d'info (version exposée = **IOC** utile en Blue, piste en Red).

> [!note] À retenir
> `IP = qui, port = quelle porte, TCP = avec accusé de réception, UDP = sans`. Le module 5 remplacera `socket` brut par `requests` pour le HTTP.

# 4. `socket` en Python (40 min, live-coding)

> [!info] Philosophie
> `socket` = lib standard, bas niveau. On manipule des **bytes**, pas des `str`. Tout appel réseau peut bloquer ou échouer : **toujours un timeout, toujours fermé, jamais d'except nu**.

## 4.1 Connexion propre avec timeout

```python
import socket


def est_ouvert(host: str, port: int, timeout: float = 2.0) -> bool:
    """Teste un port TCP. Renvoie True si ouvert, False sinon."""
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except (TimeoutError, ConnectionRefusedError, OSError):
        return False


print(est_ouvert("127.0.0.1", 8000))
```

- `create_connection` gère DNS + `connect` + timeout en une ligne.
- `with` garantit la fermeture, même en cas d'erreur.
- `OSError` couvre `socket.gaierror` et les erreurs réseau (classe parente).

## 4.2 Envoyer / recevoir (bytes)

```python
import socket


def recuperer_banniere(host: str, port: int, timeout: float = 2.0) -> str | None:
    """Se connecte, lit jusqu'à 1024 octets, renvoie la bannière décodée."""
    try:
        with socket.create_connection((host, port), timeout=timeout) as s:
            s.settimeout(timeout)
            donnees = s.recv(1024)
    except (TimeoutError, ConnectionRefusedError, OSError):
        return None
    if not donnees:
        return None
    return donnees.decode(errors="replace").strip()


print(recuperer_banniere("127.0.0.1", 8000))
```

- `recv(1024)` = jusqu'à 1024 octets, peut rendre moins — normal en TCP.
- `.decode(errors="replace")` évite le crash sur bytes non-UTF8.
- `None` = « pas de résultat » (convention module 2, test avec `is None`).

Variante avec envoi explicite (ex. sonder un service qui attend une requête) :

```python
import socket

with socket.create_connection(("127.0.0.1", 8000), timeout=2.0) as s:
    s.settimeout(2.0)
    s.sendall(b"HEAD / HTTP/1.0\r\n\r\n")
    reponse = s.recv(4096)
    print(reponse.decode(errors="replace"))
```

## 4.3 Boucle de scan locale

```python
import socket


def scanner_ports(host: str, ports: list[int], timeout: float = 1.0) -> dict[int, str]:
    """Scanne des ports TCP. Renvoie {port: 'open' | 'closed'}."""
    resultat: dict[int, str] = {}
    for port in ports:
        try:
            with socket.create_connection((host, port), timeout=timeout):
                resultat[port] = "open"
        except (TimeoutError, ConnectionRefusedError, OSError):
            resultat[port] = "closed"
    return resultat


print(scanner_ports("127.0.0.1", [22, 80, 443, 8000]))
```

# 6. Clôture et pont vers séance 5 (10 min)

- `socket` = bas niveau, verbeux, en bytes → séance 5 `requests` = haut niveau HTTP.
- Règles à garder :
  - toujours `timeout`,
  - toujours fermer (`with`),
  - attraper l'exception précise, jamais `except:` nu,
  - `decode(errors="replace")` sur tout `recv`.

> [!note] À retenir
> **Timeout + `with` + `try/except` précis = 90 % d'un client réseau fiable.** Le reste (threads, furtivité, parsing HTTP) vient en modules 5 et 6.
